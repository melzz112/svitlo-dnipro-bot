# Світло Дніпро — бот

1. `cp .env.example .env`, вписати `BOT_TOKEN` (для тесту меню без API: `SOURCE=demo`).
2. `pip install -r requirements.txt`
3. `python bot.py` — бот з меню і сповіщеннями.
4. (опційно) `python userbot.py` — читання чатів, окремий акаунт, потрібні `API_ID`, `API_HASH`, `CHATS`.

За замовчуванням (`SOURCE=dtek`) графіки ДТЕК і ЦЕК бот бере з YASNO; далі — outage-data-ua, сторінка ДТЕК (лише в крайньому разі й не під час паузи), дані юзербота з Telegram. Черги — будь-які `X.Y` (1.1 … 18.1 і далі): кнопки й розбір будуються з даних. [Графіки YASNO для Дніпра](https://static.yasno.ua/dnipro/outages).

**Зміни графіків YASNO.** Слоти кожної черги зберігаються в `schedule_snapshots`; при будь-якій правці підписники черги отримують «🔄 графік змінився · Було / Стало / ➕ Додали / ➖ Прибрали».

**Довідник вулиць і будинків.** Повний перелік вулиць і будинків Дніпра з чергами (і будинки без черги) лежить у `dtek_streets` / `dtek_houses`. Збирається з ПК з українським IP:

    python scripts/seed_streets.py --db-path dtek_seed.db --concurrency 3

Ctrl+C — зупинка, повторний запуск докачує решту. Перенести в робочу БД на сервері (користувачів не чіпає):

    python scripts/seed_streets.py --import-from dtek_seed.db --db-path /data/svitlo.db

**Сайт ДТЕК на сервері — бережно.** Раз на 30 хв (`DTEK_POLL_INTERVAL_SEC`) лише вулиці, де є підписники (адреси людей, будинки без черги, адреси «⏳ чекає на сайт»), 3–5 с між запитами; помилка чи антибот — 30 хв тиші (`DTEK_BACKOFF_SEC`). Клієнт — curl_cffi з відбитком Chrome, проксі не потрібен. Аварія з часом ремонту -> жителям будинку особистий пуш, а всім у черзі — одне зведене «🚧 аварія на адресах групи» на (черга, причина, кінець) без дублів між вулицями й каналами (`group_incidents`); активна аварія видно в «⚡ Зараз».

**Адреса людини — сповіщення по будинку.** ⚙️ Налаштування → «📍 Вказати адресу» (або «Не знаю групу» при виборі
групи): людина надсилає геопозицію кнопкою Telegram або пише адресу («Яворницького 3»). Геопозиція -> вулиця й будинок
через OpenStreetMap Nominatim (`address.py`; координати не зберігаються), вулиця зіставляється з переліком вулиць
сайту ДТЕК, будинок шукається спершу в довіднику (0 запитів), інакше через «Перевірити адресу» — звідти ж група (ставиться сама; немає черги — бот стежить за самим будинком). Будинку немає в даних
ДТЕК — бот пропонує обрати ЦЕК і групу вручну (у ЦЕК такої перевірки немає). Далі вулиці людей перевіряються
(по запиту на вулицю, хоч скільки там людей), і людина отримує особисті пуші: «🏠 У твоєму будинку
немає світла · екстрене відключення до 18:05», «продовжено/скорочено» (зсув ≥30 хв), «✅ світло мало з'явитися»
(після двох перевірок поспіль), «ДТЕК переніс будинок у групу X». «⚡ Зараз» починається з блоку «🏠 Твій будинок».
Зберігаються лише вулиця і номер будинку (`users.street`, `users.house`), видалити — «🗑 Видалити адресу». Окремо бот читає вікно «Шановні клієнти!»: коли в м. Дніпро діють екстрені
й графік не працює, пуш отримують усі абоненти ДТЕК, «Зараз» і «Графік» показують, що графік не діє,
а нагадування «через 15 хв вимкнуть» не надсилаються. Перевірити вулиці вручну: `python dtek_site.py вул. …`.

Файли: `providers.py` (графіки), `dtek_site.py` (екстрені по групах і будинках з сайту ДТЕК),
`address.py` (геопозиція/текст -> вулиця й будинок), `cek_site.py` (стрічка «Відключення» на сайті ЦЕК: графік ГПВ,
«додатково відключаються черги», екстрені; поки не підключений як джерело — `python cek_site.py`), `parse.py` (розбір чатів + цензура),
`handlers.py`/`keyboards.py` (меню), `notifier.py` (пуші), `db.py` (SQLite).

Тести: `PYTHONPATH=. python -m unittest discover -s tests -p "test_*.py"`, а також `python tests/test_parse_live.py`
і `python tests/test_schedule_posts.py`.

**Автооновлення на сервері (не встановлено).** Зараз сервер — не git-checkout (деплой архівом), а для приватного
репозиторію потрібен ключ доступу; до того ж кожен push одразу йшов би в роботу без перевірки. Якщо все ж треба —
один раз із папки бота:
`(crontab -l 2>/dev/null; echo "*/2 * * * * $(pwd)/deploy/autoupdate.sh >> $(pwd)/autoupdate.log 2>&1") | crontab -`
Далі раз на 2 хв сервер перевіряє гілку на GitHub і, якщо є нові коміти, сам робить `git pull` і перезбирає бота.
Лог — `autoupdate.log`.
