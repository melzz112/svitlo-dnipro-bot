# Світло Дніпро — бот

1. `cp .env.example .env`, вписати `BOT_TOKEN` (для тесту меню без API: `SOURCE=demo`).
2. `pip install -r requirements.txt`
3. `python bot.py` — бот з меню і сповіщеннями.
4. (опційно) `python userbot.py` — читання чатів, окремий акаунт, потрібні `API_ID`, `API_HASH`, `CHATS`.

За замовчуванням (`SOURCE=dtek`) бот спочатку перевіряє сайт ДТЕК, далі шукає графік на YASNO. Графік ЦЕК бот бере з YASNO. З `SOURCE=yasno` бот звертається до YASNO для обох операторів. Якщо графіка на сайтах немає, бот перевіряє дані, збережені юзерботом з Telegram. [Графіки YASNO для Дніпра](https://static.yasno.ua/dnipro/outages).

**Екстрені відключення.** Раз на 3 хв (`DTEK_PROBE_SEC`) бот перевіряє на сайті ДТЕК («Перевірити адресу») кілька
довгих вулиць (`DTEK_STREETS`): по кожному будинку сайт показує його чергу і причину, якщо світла немає. Якщо в групі
від 20% контрольних адрес стоїть «Екстренні відключення», люди цієї групи одразу отримують пуш, а «⚡ Зараз»
показує «🔴 Світла немає · екстрене відключення до …». Менше 20% — пуша групі немає, але «Зараз» показує
«🏠 Сайт ДТЕК: екстрене у 30 з 265 перевірених адрес групи, до 18:05». Коли за тими ж адресами світло повертається,
приходить «✅ екстрене закінчилось». Сайт закрився антиботом — наступна спроба за 15 хв.

**Адреса людини — сповіщення по будинку.** ⚙️ Налаштування → «📍 Вказати адресу» (або «Не знаю групу» при виборі
групи): людина надсилає геопозицію кнопкою Telegram або пише адресу («Яворницького 3»). Геопозиція -> вулиця й будинок
через OpenStreetMap Nominatim (`address.py`; координати не зберігаються), вулиця зіставляється з переліком вулиць
сайту ДТЕК, будинок шукається через «Перевірити адресу» — звідти ж група (ставиться сама). Будинку немає в даних
ДТЕК — бот пропонує обрати ЦЕК і групу вручну (у ЦЕК такої перевірки немає). Далі вулиці людей перевіряються разом
з контрольними (по запиту на вулицю, хоч скільки там людей), і людина отримує особисті пуші: «🏠 У твоєму будинку
немає світла · екстрене відключення до 18:05», «продовжено/скорочено» (зсув ≥30 хв), «✅ світло мало з'явитися»
(після двох перевірок поспіль), «ДТЕК переніс будинок у групу X». «⚡ Зараз» починається з блоку «🏠 Твій будинок».
Зберігаються лише вулиця і номер будинку (`users.street`, `users.house`), видалити — «🗑 Видалити адресу». Окремо бот читає вікно «Шановні клієнти!»: коли в м. Дніпро діють екстрені
й графік не працює, пуш отримують усі абоненти ДТЕК, «Зараз» і «Графік» показують, що графік не діє,
а нагадування «через 15 хв вимкнуть» не надсилаються. Перевірити, чи покриті всі групи: `python dtek_site.py`.

Файли: `providers.py` (графіки), `dtek_site.py` (екстрені по групах і будинках з сайту ДТЕК),
`address.py` (геопозиція/текст -> вулиця й будинок), `parse.py` (розбір чатів + цензура),
`handlers.py`/`keyboards.py` (меню), `notifier.py` (пуші), `db.py` (SQLite).

Тести: `PYTHONPATH=. python -m unittest discover -s tests -p "test_*.py"`, а також `python tests/test_parse_live.py`
і `python tests/test_schedule_posts.py`.

**Автооновлення на сервері (не встановлено).** Зараз сервер — не git-checkout (деплой архівом), а для приватного
репозиторію потрібен ключ доступу; до того ж кожен push одразу йшов би в роботу без перевірки. Якщо все ж треба —
один раз із папки бота:
`(crontab -l 2>/dev/null; echo "*/2 * * * * $(pwd)/deploy/autoupdate.sh >> $(pwd)/autoupdate.log 2>&1") | crontab -`
Далі раз на 2 хв сервер перевіряє гілку на GitHub і, якщо є нові коміти, сам робить `git pull` і перезбирає бота.
Лог — `autoupdate.log`.
